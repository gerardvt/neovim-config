# Migration Plan: lazy.nvim → vim.pack, nvim-lspconfig → vim.lsp.config, blink.cmp → vim.lsp.completion

## Context

Neovim 0.12 ships three built-ins that replace external plugins:
- **`vim.pack`** — native package manager (replaces lazy.nvim)
- **`vim.lsp.config()` / `vim.lsp.enable()`** — native LSP server config (replaces nvim-lspconfig)
- **`vim.lsp.completion`** — native LSP completion (replaces blink.cmp)

Additionally dropping:
- **Mason** (mason.nvim, mason-lspconfig, mason-tool-installer) — LSP binaries installed manually per language toolchain
- **lazydev.nvim** — replaced by manually setting `lua_ls` workspace library

The OSCYank `<leader>y` keymaps in `keymappings.lua` reference a plugin that was never in `lazy-lock.json` (never installed). These will be removed; yanking already uses the system clipboard via `clipboard:append("unnamedplus")`.

## `init.lua` — Stays Minimal

`init.lua` only loads three things. All plugin installation and setup is delegated to `packages.lua`:

```lua
require('config.options')
require('config.keymappings')
require('config.packages')   -- installs all plugins AND runs their setup
```

## Files to Create

### `lua/config/packages.lua`
Replaces `lazy-plugins.lua`. Responsible for:
1. Installing all plugins via `vim.pack.add()` using the `{ src = '...' }` table form.
2. Requiring each plugin's setup file after installation.
3. Requiring the LSP config.

```lua
-- Install plugins
vim.pack.add({
    { src = 'https://github.com/nvim-telescope/telescope.nvim' },
    { src = 'https://github.com/nvim-lua/plenary.nvim' },
    { src = 'https://github.com/nvim-lualine/lualine.nvim' },
    { src = 'https://github.com/nvim-tree/nvim-web-devicons' },
    { src = 'https://github.com/folke/which-key.nvim' },
    { src = 'https://github.com/echasnovski/mini.icons' },
    { src = 'https://github.com/lukas-reineke/indent-blankline.nvim' },
    { src = 'https://github.com/j-hui/fidget.nvim' },
    { src = 'https://github.com/mikesmithgh/kitty-scrollback.nvim' },
})

-- Plugin setup
require('plugins.telescope')
require('plugins.lualine')
require('plugins.whichkey')
require('plugins.indentblankline')
require('plugins.kitty-scrollback')
require('plugins.fidget')

-- LSP + completion
require('plugins.lsp')
```

## Files to Rewrite

### `lua/plugins/lsp.lua`
Full rewrite using native APIs. Structure:

1. **Global capabilities** (snippet support for all servers):
```lua
vim.lsp.config('*', {
    capabilities = {
        textDocument = { completion = { completionItem = { snippetSupport = true } } }
    }
})
```

2. **Per-server configs** via `vim.lsp.config('name', { cmd, filetypes, root_markers, settings })`:
   - `hls` — cmd: `haskell-language-server-wrapper --lsp`, filetypes: haskell/lhaskell/cabal
   - `clangd` — cmd: `clangd`, filetypes: c/cpp/objc/objcpp
   - `gopls` — cmd: `gopls`, filetypes: go/gomod/gowork/gotmpl
   - `pyright` — cmd: `pyright-langserver --stdio`, filetypes: python
   - `rust_analyzer` — cmd: `rust-analyzer`, filetypes: rust
   - `lua_ls` — cmd: `lua-language-server`, with workspace library set to `vim.api.nvim_get_runtime_file('', true)` and `checkThirdParty = false` (replaces lazydev)

3. **`vim.lsp.enable()`** for all 6 servers.

4. **`LspAttach` autocommand**:
   - `setupLspBufferKeyBindings(buffer)` — all `gr*` and `gs*` keymaps (unchanged, Telescope calls preserved)
   - Inlay hints toggle `<leader>th`
   - Document highlight autocommands (CursorHold/CursorMoved)
   - `vim.lsp.completion.enable(true, client.id, buffer, { autotrigger = true })` if server supports `textDocument/completion`

5. **Diagnostic config** — unchanged from current config.

6. **Global completeopt**:
```lua
vim.opt.completeopt = 'menu,menuone,noselect,popup'
```

### `lua/plugins/telescope.lua`
Strip the `return { 'nvim-telescope/telescope.nvim', ... }` lazy spec wrapper.
Keep all `require('telescope').setup(...)` and keymap code directly (no `return`).

### `lua/plugins/indentblankline.lua`
Strip lazy spec. Call `require('ibl').setup({})` directly.

### `lua/plugins/kitty-scrollback.lua`
Strip lazy spec (remove cmd/event lazy triggers). Call `require('kitty-scrollback').setup()` directly.

## Verification

1. Launch nvim — vim.pack installs plugins on first run, subsequent launches load from disk.
2. `:checkhealth` — verify LSP binaries are found on PATH.
3. Open a `.go`, `.rs`, `.py`, `.lua`, `.c`, `.hs` file — verify LSP attaches (fidget shows spinner).
4. Type in insert mode — verify completion popup appears automatically.
5. Test `grn` (rename), `grd` (definition), `grr` (references via Telescope), `gra` (code action).
6. Test `<leader>ff`, `<leader>fg` (Telescope).
7. Test `<leader>t` (floating terminal).
8. Test `<leader>th` (toggle inlay hints) in a Go or Rust file.
